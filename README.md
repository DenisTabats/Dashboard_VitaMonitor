# ВитаМонитор (https://denistabats.github.io/Dashboard_VitaMonitor/)

Курсовой проект: цифровой медицинский дашборд для наблюдения за состоянием пациента и подготовки диагностических консилиумов.

Проект выполнен группой ПИУКИС-23: Глазко Илья (front-end), Елинскас Диана (контент), Табацкий Денис (тимлид). Донецк, 2026.

## Страницы

- `index.html` — экран смены: сводка по отделению, таблица пациентов, консилиумы на сегодня и передача смены.
- `dashboard.html` — карта пациента: список наблюдения, вкладки «Обзор», «Записи» и «Консилиумы», показатели, лист наблюдения и графики.

## Возможности

- таблица пациентов с поиском и фильтром по статусу
- переход в карту пациента без перезагрузки страницы
- вкладки «Обзор», «Записи» и «Консилиумы»
- цветовая индикация отклонений показателей
- добавление записи врача
- создание запроса на консилиум с выбранной специальностью
- черновик передачи смены
- адаптивная вёрстка для телефона и компьютера
- навигация с клавиатуры и подписи для интерактивных элементов

## Стек

- HTML5
- CSS3 без фреймворков
- чистый JavaScript ES2015+
- `localStorage` для записей, консилиумов и передачи смены


## Данные

Пациенты находятся в `js/patients.js`. Записи врача, консилиумы и передача смены сохраняются в браузере под ключами:

- `vitamonitor_notes_v1`
- `vitamonitor_consiliums_v1`
- `vitamonitor_handover_v1`
